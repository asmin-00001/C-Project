# ✊✋✌️ Rock Paper Scissors Game (C++)

A simple **console-based Rock Paper Scissors game** built using C++. This project is great for beginners who want to understand basic concepts like conditionals, loops, functions, and random number generation.

---

## 📌 Features

- Play against the computer
- Random computer moves
- Score tracking (optional if you added it)
- Simple and interactive console interface
- Beginner-friendly C++ code

---

## 🧠 Concepts Used

- Conditional statements (`if`, `else if`, `else`)
- Loops (`while` / `for`)
- Functions
- Random number generation (`rand()`)
- User input handling (`cin`, `cout`)

---

## 🛠️ Requirements

- C++ compiler (GCC, MinGW, or Clang)
- Any IDE or terminal (VS Code recommended)
